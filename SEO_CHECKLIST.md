## ✅ Image Optimization Checklist

For EVERY photo you upload:

- [ ] **Filename**: descriptive-with-location-barcelona.avif
  - Good: `gothic-quarter-love-story-couple-barcelona.avif`
  - Bad: `IMG_1234.avif`

- [ ] **Alt Text**: Detailed description + location + Barcelona
  - Good: `Romantic couple holding hands during sunset photoshoot at Gothic Quarter Barcelona`
  - Bad: `Couple photo`

- [ ] **File Size**: Under 500KB (preferably under 200KB)
  - Use compression tools
  - Already using .avif format ✅

- [ ] **Dimensions**: Appropriate for use
  - Hero images: 1920x1080px
  - Gallery thumbs: 800x600px
  - Social sharing: 1200x628px
