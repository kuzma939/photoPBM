# Image Alt Text Guide for Barcelona Photography SEO

## 🎯 Why Alt Text Matters for SEO

Alt text (alternative text) helps:
1. **Google Image Search** - Makes your photos discoverable
2. **Accessibility** - Screen readers for visually impaired users
3. **SEO Rankings** - Google understands what's in your images
4. **User Experience** - Shows when images fail to load

## ✅ Alt Text Formula for Photography

```
[Subject] + [Action/Emotion] + [Location] + [City]
```

### Examples:

**Instead of:** `IMG_1234.jpg` or `photo.avif`

**Use:** 
- `Romantic couple holding hands during sunset photoshoot at Gothic Quarter Barcelona`
- `Happy family portrait session at Barceloneta Beach Barcelona`
- `Bride and groom kiss under Sagrada Familia Barcelona wedding photography`
- `Engagement ring closeup with Barcelona cityscape background`

## 📊 Alt Text Best Practices

### Length:
- **Optimal:** 100-125 characters
- **Maximum:** 150 characters
- **Minimum:** 50 characters

### Structure:
1. **Start with main subject** (couple, family, bride, etc.)
2. **Add action or emotion** (walking, laughing, embracing, etc.)
3. **Include location** (Gothic Quarter, Sagrada Família, etc.)
4. **End with city** (Barcelona)

### Language:
- Use natural, descriptive language
- Write for humans first, search engines second
- Be specific but concise
- Include emotions and atmosphere

## 🛠️ How to Add Alt Text in Next.js

### For Static Images:

```jsx
<Image
  src="/Gothic/couple-photo.avif"
  alt="Romantic couple walking through medieval streets Gothic Quarter Barcelona"
  width={1200}
  height={800}
/>
```

### For Dynamic Gallery Images:

```jsx
{images.map((img, index) => (
  <Image
    key={index}
    src={img.url}
    alt={`${img.type} photography session at ${img.location} Barcelona`}
    width={800}
    height={600}
  />
))}
```

### For Background Images:

```jsx
<div 
  style={{ backgroundImage: `url(${image})` }}
  role="img"
  aria-label="Love story couple photoshoot Gothic Quarter Barcelona"
>
```

## 🔍 Testing Your Alt Text

1. **Inspect in browser:**
   - Right-click image → Inspect
   - Check for `alt=""` attribute
   - Verify text is descriptive

2. **Disability Mode:**
   - Turn off images in browser
   - Alt text should make sense alone
   - Context should be clear

3. **SEO Check:**
   - Contains location keywords? ✓
   - Contains session type? ✓
   - Natural language? ✓
   - Under 150 characters? ✓

## 💡 Pro Tips

1. **Unique alt text** - Never duplicate across images
2. **No keyword stuffing** - Write naturally
3. **Skip "image of" or "photo of"** - Screen readers announce it's an image
4. **Include people's emotions** - "laughing", "intimate", "joyful"
5. **Location, location, location** - Always include Barcelona + specific spot
6. **Update old images** - Improve alt text on existing photos
7. **Be consistent** - Use similar structure across all images
